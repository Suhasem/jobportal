Job Portal

A Spring Boot-based Job Portal application designed to connect job seekers and recruiters through a secure, well-structured backend.

Key Features
3-Layer Architecture — clean separation between Controller, Service, and Repository layers for maintainability and scalability
JWT Authentication — secure, stateless user authentication and authorization
Global Exception Handling — centralized error handling for consistent, predictable API responses
Tech Stack
Java, Spring Boot
Spring Security (JWT)
Spring Data JPA
